\author{Aviskar~Giri and Isaac~Corley%

\begin{abstract}
Gaps in predicted boundaries can merge neighboring agricultural fields, and spurious interior edges can split a field into several polygons.
These errors affect field-level monitoring even when most pixels are classified correctly.
We introduce FieldVote, a consensus polygonization method that combines watershed outputs from a frozen segmentation network.
Instead of selecting one h-minima depth for an entire region, FieldVote rasterizes the polygons obtained across a depth sweep, thresholds their mean foreground support, and vectorizes the resulting mask.
The rule requires neither additional training nor reference polygons at inference.
We evaluate PlanetScope predictions on the held-out test splits of ten densely annotated countries from Fields of The World.
FieldVote raises macro panoptic quality from \BasePQ{} to \VotePQ{} relative to a country-selected watershed, and the gain persists with vector annotations.
It improves scores in seven countries but reduces them in Cambodia, Portugal, and Germany.
\end{abstract}

\begin{IEEEkeywords}

\section{Introduction}
\IEEEPARstart{A}{gricultural} monitoring uses field polygons to group observations by parcel.
Merging neighboring parcels pools their measurements, while splitting one parcel changes the objects being counted and monitored.
Satellite segmentation models predict field interiors and boundaries~\cite{kerner2024ftw,waldner2020decode,corley_ftp}.
Converting these predictions into field polygons requires deciding which separations define individual parcels.
Thin structures that occupy only a small fraction of the image can change those divisions (Fig.~\ref{fig:pipeline}).

Marker-controlled watershed converts a segmentation mask into field instances~\cite{soille2004morphological,waldner2020decode}.
Its h-minima depth controls which local minima become markers.
Shallow suppression can retain spurious markers and fragment fields, while stronger suppression removes markers and can merge neighboring fields.
The best depth in our evaluation varies across countries, from 0.75 in Cambodia to 12 in Sweden.
Tuning a depth to each region's polygon accuracy requires reference polygons, which may be unavailable at deployment.
We instead combine the available predictions without using local annotations.

\method{} combines watershed predictions across h-minima depths.
Varying the depth changes the marker configuration and reveals which parts of the predicted field support persist across runs.
We rasterize these polygon sets on a common grid, take a pixelwise vote, and polygonize the consensus.
Separations present in only a minority of runs can disappear, joining fragments of the same parcel.
The vote can also remove true separations, so agreement across depths does not guarantee correct field boundaries.

Hierarchical segmentation represents contours at multiple strengths and produces partitions at different levels~\cite{arbelaez2011hierarchical,maninis2018cob}.
Iterative h-minima methods also use changes in watershed markers~\cite{koyuncu2016iterative}.
We evaluate foreground consensus for field polygonization using fixed predictions from the Fields of the Planet model~\cite{corley_ftp}.
The experiments compare aggregation strategies on ten countries, measure sensitivity to the reference representation, and identify regional failures.
Changing the polygonization method improves macro panoptic quality by \GainPQ{} points with the network predictions held fixed.

\section{Method}
\label{sec:method}
\method{} takes a set of watershed polygon predictions for the same image.
The underlying network and its predictions remain fixed.
Let $\mathcal{P}_k$ denote the polygon set obtained at depth $h_k$, and let $R(\mathcal{P}_k)(p)$ be its binary rasterization at pixel $p$ on a shared georeferenced grid.
Each raster records whether a polygon covers a pixel, discarding the instance labels before averaging.

\subsection{Foreground Consensus}
We form the vote fraction and consensus mask as
\begin{equation}
 v(p)=\frac{1}{K}\sum_{k=1}^{K}R(\mathcal{P}_k)(p),
 \qquad M(p)=\mathbb{1}[v(p)\geq\tau],
 \label{eq:vote}
\end{equation}
with $\tau=0.5$.
We extract polygons from the four-connected foreground components of $M$.
For an even number of runs, ties are assigned to foreground, so a pixel needs at least $\lceil K/2\rceil$ foreground votes.
A run with no polygons at a patch contributes a zero mask.

The vote combines polygon support without averaging contour coordinates or instance identities.
A gap excluded by enough runs remains a separation, while a gap covered by at least half of the runs can be filled.
The output can join fragments without selecting a complete watershed result.
If every run covers exactly the same foreground pixels and changes only their instance labels, the vote is unchanged.
The input rasters must preserve gaps between polygons for the vote to distinguish their boundaries.

The candidate sweep is
\begin{equation}
\begin{split}
H=\{&0.5,\,0.75,\,1,\,1.25,\,1.5,\,2,\,4,\,8,\,12,\\
    &16,\,24,\,32,\,48,\,64\}.
\end{split}
\label{eq:depths}
\end{equation}
The implementation loads the available country-level polygon exports from this set, so $K\leq14$.
The threshold $\tau$ is shared across countries.
Although the voting rule does not use reference polygons, its output still depends on the sweep and threshold.
The foreground masks have equal weight even though the candidate depths are not uniformly spaced.

\subsection{Implementation}
We use Rasterio to rasterize each polygon set with the reference raster's shape and affine transform, then extract the connected components as polygons.
The vote uses the raster grid without reading its label values, which are used only for scoring.
At deployment, imagery metadata can provide a grid with the same spatial convention.
The consensus stage accumulates a vote count per pixel without storing all $K$ masks at once.
Raster accumulation scales linearly with $K$, in addition to the cost of producing the candidate polygons with the watershed sweep.

\section{Experiments}
\label{sec:experiments}

\subsection{Setup}
We use predictions from the frozen PlanetScope UNet released with Fields of the Planet~\cite{corley_ftp}.
The model has an EfficientNet-B7 encoder and predicts field interior, boundary, and background.
Our evaluation uses the held-out test splits of ten densely annotated Fields of The World countries~\cite{kerner2024ftw}, comprising 2,215 scored patches.
We exclude presence-only Kenya, where unlabeled fields confound false-positive counts.
Every country receives equal weight in the macro average despite differences in sample counts, including two scored patches in Portugal and sixteen in Cambodia.
No network weights are updated.

The primary baseline selects the single watershed depth with highest country-level panoptic quality using that country's test annotations.
Because it uses test annotations, the baseline gives a retrospective comparison and cannot select a depth for unlabeled data.
\method{} combines the available predictions without using those annotations in the vote.
Both methods use the same frozen network.
The comparison measures the complete polygonization paths, including the rasterization and vectorization used by \method.

We use panoptic quality (PQ)~\cite{kirillov2019panoptic} to evaluate field instances beyond pixel-level foreground accuracy.
Predicted and reference polygons are matched at an intersection-over-union threshold of 0.5.
Segmentation quality (SQ) measures mean overlap among matches, and recognition quality (RQ) is the corresponding object F1 score.
We pool matches and detection counts over each country's patches and compute PQ as SQ$\times$RQ within that country.
We then average country scores and report them on a 0--100 scale.
Macro PQ need not equal the product of macro SQ and macro RQ.

The primary reference consists of connected field-interior components in the released semantic masks.
We also rescore predictions against the released vector annotations, clipped to each evaluation patch.
Vector annotations preserve parcel divisions that may disappear when touching regions are reduced to semantic connected components.
Both reference conventions describe the same evaluation regions, so the two sets of scores are not independent.

\subsection{Polygon Accuracy}
\method{} raises macro PQ by \GainPQ{} points over the country-selected watershed (Table~\ref{tab:main}).
A paired, two-sided Wilcoxon signed-rank test over ten country scores gives $p=\CountryPValue{}$.
A percentile bootstrap of the mean country difference gives a 95\% interval of $[\GainLow{},\GainHigh{}]$ points (100,000 country resamples).
The interval describes variation across the evaluated countries without measuring training-seed variability or establishing performance in an unseen region.
Rescoring against vector annotations retains the gain, with macro PQ of \VectorVotePQ{} versus \VectorBasePQ{}.

\method{} improves PQ in seven countries, with the largest gains in Belgium and Croatia, but reduces PQ in Cambodia, Portugal, and Germany (Fig.~\ref{fig:countries}).
The country-level losses mean that the gain in macro PQ is insufficient to recommend the method for every local parcel regime.
Portugal has only two scored patches compared with 590 in Latvia, so its result has less within-country coverage despite equal macro weight.

\subsection{Aggregation Strategies}
We compare three ways of combining the available watershed predictions (Table~\ref{tab:aggregation}).
Polygon pooling ranks candidates by overlap agreement and applies non-maximum suppression (NMS).
Count-based selection chooses one depth per patch where the relative change in polygon count between adjacent depths is smallest.
Both operate on the same candidate polygon exports as \method{} and require no reference annotations for selection.

Pixel voting has higher PQ than either alternative, with a larger difference in RQ than SQ.
The larger change in RQ is consistent with changes in recovered field instances.
The comparison includes both voting and the common-grid conversion that precedes it.
A one-depth rasterize--polygonize control is needed to measure how much of the gain comes from grid conversion alone.

\subsection{Qualitative Behavior and Limitations}
In Lithuania, \method{} removes thin internal fragments but misses annotated divisions within the large fields (Fig.~\ref{fig:qualitative}).
In Croatia, it removes repeated cross-field splits from the narrow parcels while leaving several annotated fields undetected.
Voting cannot reliably reconstruct a field absent from the candidate predictions.
Fewer polygons do not necessarily indicate more accurate delineation.

The experiments use one frozen PlanetScope model, so transfer to other architectures or sensors remains untested.
The candidate depth spacing, available exports, and rasterization grid can all influence the vote.
A fixed majority threshold may preserve persistent false boundaries and erase weak true boundaries.
Small-parcel delineation remains unresolved and requires evaluation with adequate regional coverage and instance-preserving annotations~\cite{persello2023ai4smallfarms,dandrimont2023ai4boundaries}.

\section{Conclusion}
\method{} combines watershed polygon support across depths to recover field instances from fixed network predictions.
Across ten countries, the method improves macro PQ under both semantic-mask and vector-reference scoring.
Gains vary by country, and the output still misses parcel divisions.
Further evaluation should isolate the effect of grid conversion and establish how to preserve weak boundaries in small fields.
